# gradient-descent-cbt-hackathon — `gnn` branch

Experimental branch for building a **Graph Neural Network (GNN)** as part of the Gradient Descent CBT hackathon project.

> [!WARNING]
> This branch is a sandbox for GNN experiments. Expect breaking changes, unfinished code, and rewritten history. Don't depend on it for anything stable.

## Overview

This is where we try out GNN approaches for the project: model architectures, graph construction, training loops, and evaluation. Ideas that work will be cleaned up and merged into `main`.

## Getting started

```bash
git clone https://github.com/ShriVarshaan/gradient-descent-cbt-hackathon.git
cd gradient-descent-cbt-hackathon
git switch gnn
```

> [!NOTE]
> There's no code here yet. Setup steps, dependencies, and usage instructions will be added as the experiments come together.
